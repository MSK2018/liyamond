# Liyamond

فروشگاه لیاموند با Next.js و MongoDB.

## راه‌اندازی محلی

1. یک MongoDB محلی اجرا کنید.
2. فایل `.env.example` را به `.env.local` کپی کنید. مقدار `MONGODB_URI` را در صورت نیاز تغییر دهید.
3. وابستگی‌ها را نصب و برنامه را اجرا کنید:

   ```bash
   npm install
   npm run dev
   ```

صفحه‌ی `/shop` محصولات فعال را از MongoDB می‌خواند. اگر `MONGODB_URI` تنظیم نشده باشد یا پایگاه داده در دسترس نباشد، خطای اتصال در سرور نمایش داده می‌شود؛ برنامه عمداً به داده‌ی نمونه یا نتیجه‌ی خالیِ ساختگی برنمی‌گردد.

## مدل‌های فعلی

- `Category`: نام، slug یکتا، توضیحات، دسته‌ی والد و وضعیت فعال.
- `Product`: نام، slug یکتا، توضیحات، تصاویر، دسته، قیمت صحیح به تومان، موجودی و وضعیت انتشار.

محصول‌ها به‌صورت پیش‌فرض غیرفعال‌اند و فقط محصولات فعال در فروشگاه نمایش داده می‌شوند. آدرس اتصال MongoDB را در `.env.local` نگه دارید و آن را در مخزن Git قرار ندهید.
